# Worked Example

This shows what [SKILL.md](../SKILL.md) produces, using *The Art of War* (Sun Tzu), which is old enough to be public domain everywhere. I structured only three of the original 13 chapters, enough to show the shape without copying a whole book into this repository.

- [index.md](index.md): the index that always loads
- [chapters/](chapters/): one file per chapter, setting out the ideas rather than the original prose
- [techniques-and-patterns.md](techniques-and-patterns.md): every named method across the three chapters, with where it came from
- [glossary.md](glossary.md): key terms that keep coming up

This is a demonstration. It doesn't mean this repository contains or shares any book. The three chapter files paraphrase and structure well-known, public-domain ideas; they don't copy any particular translation.
