# Worked Example Two: A Policy, Not a Book

Shows the one genuine difference between structuring a book and structuring a policy: a book rarely contradicts itself between chapters, a policy often does.

- [source-material.md](source-material.md): a fictional two-section internal remote work policy, where the later section genuinely conflicts with the earlier one on the surface
- [index.md](index.md): the structured index, correctly flagging the contradiction and noting that the later, more specific section supersedes the earlier one only for the roles it names, rather than silently picking one or presenting both as equally valid

This is deliberately lighter than [the first worked example](../example/), two sections rather than a full set of chapters, since the point here is the contradiction-check step specifically, not a repeat of the same demonstration.
