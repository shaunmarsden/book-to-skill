# Worked Example

This illustrates the format requested by [SKILL.md](../SKILL.md), using ideas from *The Art of War* (Sun Tzu). I structured three chapters to show the shape. The repository does not identify the edition or translation used, so source fidelity and the rights to a particular edition have not been established here.

- [index.md](index.md): a short index of the three chapters
- [chapters/](chapters/): one file per chapter, setting out the ideas rather than the original prose
- [techniques-and-patterns.md](techniques-and-patterns.md): four technique summaries, each linked to a chapter file
- [glossary.md](glossary.md): key terms that keep coming up

This is a demonstration, not a complete book. The three chapter files contain summaries and interpretations. Without an identified source text, I cannot present them as a checked summary of a particular translation.

The repository doesn't record which model wrote these files, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
