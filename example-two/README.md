# Worked Example Two: A Policy, Not a Book

This illustrates how an index can record a policy update that applies to some roles but not others. The source explicitly says which earlier requirement it replaces, so this is not an unresolved contradiction.

- [source-material.md](source-material.md): a made-up internal remote work policy in two sections, with a later update for confirmed remote-eligible roles
- [index.md](index.md): the structured index, which records that the later section replaces the earlier attendance requirement only for roles confirmed as remote-eligible

It's lighter than [the book example](../example/) on purpose. It contains the source and index, not a full set of section files, a techniques document or a separate glossary. It illustrates the scoped update rather than the complete output structure.

The repository doesn't record which model wrote this index, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
