# Worked Example Two: A Policy, Not a Book

This shows the one real difference between structuring a book and structuring a policy. A book rarely contradicts itself between chapters; a policy often does.

- [source-material.md](source-material.md): a made-up internal remote work policy in two sections, where the later section seems to conflict with the earlier one
- [index.md](index.md): the structured index, which flags the contradiction and notes that the later, more specific section overrules the earlier one only for roles confirmed as remote-eligible. It doesn't quietly pick one, or present both as equally valid

It's lighter than [the first worked example](../example/) on purpose, with two sections rather than a full set of chapters, since the point here is the contradiction check, not a repeat of the same demonstration.

The repository doesn't record which model wrote this index, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
