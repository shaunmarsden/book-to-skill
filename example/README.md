# Worked Example

This shows what running [SKILL.md](../SKILL.md) actually produces, using *The Art of War* (Sun Tzu), a text old enough to be public domain everywhere. Only three of the original thirteen chapters are structured here, enough to show the shape without reproducing a full book in this repository.

- [index.md](index.md) — the always-loaded index
- [chapters/](chapters/) — one file per chapter, structured concepts rather than the original prose
- [techniques-and-patterns.md](techniques-and-patterns.md) — every named method across the structured chapters, with its source
- [glossary.md](glossary.md) — key recurring terms

This is a demonstration, not a claim that this repository contains or distributes any book. The three chapter files below paraphrase and structure widely known, public-domain ideas; they do not reproduce any specific translation's text.
