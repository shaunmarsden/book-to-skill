# Human Review Checklist

Go through this before you rely on the files it builds.

- [ ] The index stays short (roughly 100 lines or under) and points to the glossary and techniques document rather than repeating them
- [ ] Each chapter or section file sets out the content in a structure, rather than copying long passages of the original
- [ ] For a policy or training course, the index flags any contradiction between sections rather than quietly picking one side
- [ ] You have the legal right to use this source this way, and the output stays private, not published or shared
- [ ] You've checked at least one section file against the original before relying on it for something that matters
